# Tip Prediction using Machine Learning

## 📌 Overview
This project predicts whether a customer gives a high tip based on total bill and group size.

## 📊 Dataset
- Seaborn "tips" dataset

## 🔍 EDA
- head()
- describe()
- isnull()

## 📈 Visualizations
- Histogram
- Scatter plot
- Boxplot

## 🤖 Model
- Logistic Regression

## 🚀 How to Run
Open the notebook and run all cells.

## 📌 Output
Example:
Total Bill = 20, Size = 3 → High probability of tip
